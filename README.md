1. To initialize the project, first figure out the IP of the Raspberry Pi. To do this, type "hostname -I" into the Raspberry Pi command prompt and copy the address (You may need to figure out which address is the correct one)
2. Ensure that both the local machine and the Raspberry Pi are connected to the same network (public networks do not work well)
3. Now run the server.py file on the rpi
4. Run the client.py file on the desktop/laptop
5. Now the program should be up and running and ready to go
